# ai-exam-evaluator
এটি একটি আধুনিক এআই (AI) ভিত্তিক স্বয়ংক্রিয় উত্তরপত্র মূল্যায়ন সিস্টেম, যা শিক্ষকদের খাতা দেখার বিশাল চাপ কমাতে সাহায্য করে। ছাত্র-ছাত্রীদের হাতের লেখার খাতার ছবি আপলোড করার মাধ্যমে এই সিস্টেমটি Google Gemini AI-এর সাহায্যে লেখা পড়ে, আদর্শ উত্তরের সাথে তুলনা করে, নম্বর প্রদান করে এবং ফিডব্যাক তৈরি করে। একই সাথে সমস্ত ফলাফল ডাটাবেসে সংরক্ষণ করে!
